潮汐商路 · 隐私政策

一、我们收集哪些信息

  1. **游戏进度数据**：资金、库存、等级、商誉、签到记录等。**仅保存在您的设备本地，我们不上传、不收集、不共享**。
  2. **我们自身不收集任何个人信息**：游戏无需注册账号，无自建服务器，不采集设备信息、位置、通讯录、相册或文件。
  3. **可选登录**：若您自愿使用 TapTap 登录，我们仅获取公开身份标识（用于实名认证与防沉迷），不读取、不上传游戏存档。
  4. **广告相关**：广告由 TapTap 官方广告平台 Dirichlet（TapADN）提供，其 SDK 按其隐私政策处理广告标识（如 OAID）与广告展示/点击数据，用于投放与效果统计。

二、我们如何使用信息

  1. 本地进度数据仅用于存档与读取。
  2. 登录标识用于实名认证与防沉迷判定（未成年人时段与时长限制）。
  3. 广告数据由广告平台用于展示与统计；我们可见的是**汇总统计**（如展示次数、完成率），不含个人身份信息。

三、第三方 SDK 清单

  1. **TapSDK（TapTap 登录 / 合规认证）**——易玩（上海）网络科技有限公司；用途：账号登录、实名认证与防沉迷；收集：TapTap 公开身份标识、实名认证必要信息。
  2. **Dirichlet 广告 SDK（TapADN）**——易玩（上海）网络科技有限公司；用途：激励视频与横幅广告；收集：广告标识（OAID）、设备与网络基础信息、广告交互数据。

（以上明细亦见游戏内「设置 → 第三方 SDK 与权限」）

四、权限说明

  1. 网络权限（INTERNET / 网络状态）：**仅**用于登录与广告请求；**不联网也可完整游玩**。
  2. 本游戏**不申请**定位、通讯录、短信、相册、麦克风、相机等敏感权限。
  3. 首次启动即征求您的同意；**在您同意之前，不会初始化任何 SDK，也不会请求广告**。

五、信息存储与删除

  1. 本地数据保存在应用私有目录，卸载游戏即全部删除。
  2. 可在游戏内「存档 / 读档」面板管理三个存档槽位；彻底清除请在系统设置中清除应用数据或卸载。
  3. 实名认证信息由 TapTap 合规认证服务按其规则处理与保管；查询或删除请通过 TapTap 平台渠道申请。

六、未成年人保护

  1. 依规落实实名认证与防沉迷：未成年人仅可在周五、周六、周日及法定节假日 20:00-21:00 游玩，单日不超过 1 小时。
  2. 游戏不含付费内容；监护人可通过游戏内「实名与防沉迷」入口了解状态。

七、个人信息安全

  1. 本地存档采用 AES 加密存储；登录与广告通信由第三方 SDK 按其安全规范加密传输。
  2. 我们不会向任何第三方出售您的个人信息。

八、政策更新与联系方式

  1. 本政策更新日期：2026-10-02；重大变更将在游戏内与商店更新日志提示。
  2. 如对本政策有疑问，可通过 TapTap 游戏详情页的开发者联系方式与我们联系。
